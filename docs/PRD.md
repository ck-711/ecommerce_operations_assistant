# 电商运营助手 MVP PRD

## 目标

为中小电商团队提供围绕单个商品的运营闭环工作台：建店建档、商品与库存、诊断、内容方案、异步生成任务、经营数据和复盘。MVP 以本地可运行、可演示、可替换 AI 适配器为目标。

## 角色

| 角色 | 能力 |
| --- | --- |
| admin | 全部读写、投放建议确认、用户管理 |
| operator | 商品运营数据读写、任务操作、投放建议确认 |
| viewer | 只读 |

## 核心旅程

登录 → 创建店铺 → 创建商品/SKU → 录入竞品 → 生成诊断 → 生成主图/视频方案 → 创建异步素材任务 → 查看任务事件 → 回填经营数据 → 生成复盘报告。

## MVP 范围

- SQLite 持久化、Bearer token 登录、角色校验。
- 店铺、商品、SKU/库存、竞品、诊断、创意方案、生成任务、经营数据、复盘报告。
- AI 先使用确定性演示适配器，所有结果结构化且可编辑。
- 图片/视频生成以异步任务模拟器实现，保留外部供应商适配边界。
- 提供演示数据接口和静态单页前端。

## 明确不做

真实平台 OAuth/token、绕过登录的抓取、自动投放/扣费/预算修改、真实图片/视频生成供应商接入。

## 非功能要求

- API 统一 JSON 错误结构；写操作必须鉴权。
- 任务状态可观察、失败可重试、可取消。
- 代码不依赖外部服务，`python app.py` 即可启动。

## 假设与待确认

1. MVP 默认单租户；后续可在实体中增加 `workspace_id`。
2. 演示登录账号为 `admin/admin123`、`operator/operator123`、`viewer/viewer123`。
3. 真实模型、平台连接和生产级队列在第二阶段替换适配器。
