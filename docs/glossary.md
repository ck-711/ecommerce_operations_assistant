# 领域词汇表

| 词汇 | 定义 |
| --- | --- |
| 商品（Product） | 运营闭环的根实体，诊断、方案、任务、素材、投放和复盘均挂在商品下。 |
| SKU | 商品可售规格，拥有独立库存和库存流水。 |
| 生成任务（Generation Job） | 异步图片/视频生成执行单元，状态为 pending/running/succeeded/failed/cancelled/timeout。 |
| 素材（Asset） | 生成任务成功后落库的图片或视频，需经过人工审核。 |
| 投放建议 | 仅供人工确认的策略文本，不会自动创建广告或扣费。 |
| 投放实验 | 对素材、人群或链接进行验证的计划，状态由人工推进。 |
| 复盘 | 基于经营数据生成的周期总结和下一步动作。 |
